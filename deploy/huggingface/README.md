# Modulus

A structural design optimization engine — sweeps materials, cross-sections, and
dimensions to size beams and brackets by factor of safety, weight, and cost,
validated against an independent finite-element solver.

Python + FastAPI engine, React + TypeScript frontend, served as a single container.

**Source & docs:** https://github.com/Aaditya-Gupta24/Modulus

> This README's front-matter configures the Hugging Face Space (Docker SDK, port
> 8000). The project's own README lives in the GitHub repo above.
