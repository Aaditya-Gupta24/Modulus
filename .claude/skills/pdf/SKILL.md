# PDF Report Generation

Guidance for generating PDF design reports from MechOpt analysis results.

## Report structure
1. **Header:** Project name, date, analyst, revision
2. **Problem statement:** Load case, constraints, objectives
3. **Assumptions:** What's modeled, what's not (with warnings)
4. **Load cases:** Applied loads, boundary conditions, factors
5. **Candidate evaluation:** Material × section × dimension sweep results
6. **Failure-mode table:** Check / Value / Limit / Margin / Status per candidate
7. **Decision rationale:** Why the recommended design wins, what controls
8. **Plots:** Weight-cost tradeoff, Pareto front, sensitivity
9. **Limitations:** Unmodeled effects, applicable range, disclaimers
10. **Validation:** FE comparison, test data if available

## Implementation approach
- Use Python's built-in or lightweight PDF libraries (e.g., reportlab, or matplotlib's PDF backend for plots)
- Structure data as Python objects first, then render to PDF
- Tables should be machine-readable (not just images of tables)
- Plots embed as vector graphics where possible
- Include a "Generated by MechOpt" footer with timestamp
